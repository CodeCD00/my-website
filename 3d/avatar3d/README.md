# Cody 3D avatar

A 3D version of Cody's hand-drawn chibi (`code char/*.png`), built in Blender from his drawings.
The face is cut out of the drawings themselves, so all five expressions keep his linework.
Status: **approved** after draft 2 (Cody asked for bigger hands, which is done). Nothing here is wired into
`prototype/` yet.

| File | What it is |
|---|---|
| `cody_avatar.glb` / `.blend` | Seated, cross-legged (the hero avatar). Node pivots, no skin, one looping `Idle` clip. |
| `cody_standing.glb` / `.blend` | Standing, A-pose bind pose, 20-bone skeleton, skin weights, 4 pose clips. |
| `textures/face_<expression>.png` | The five faces (1024², sRGB): `not_talking`, `talking`, `smug`, `sure`, `evil`. |
| `cody3d.js` | Small loader: loads a glb plus the faces, optional `Ink` toon/outline setup, `setExpression()`, `setPose()`. |
| `viewer.html` | Test page using the site's own `prototype/ink.js` (imported read-only). |
| `previews/` | `final_seated_sheet.png`, `final_standing_sheet.png` and the stills behind them. `draft1/` and `draft2/` are earlier rounds. |
| `scripts/` | Everything is generated by these. See "Rebuilding" below. |

## Scale and orientation (both models)

- glTF Y up. The character faces **+Z**, toward a default three.js camera.
- **Seated:** 2.29 units tall. The origin is at the bottom centre, where he sits on the seat (lowest point y ≈ 0.006).
  Width is −0.65…+0.82 in X; the big hair swoop reaches out to his left (+X).
- **Standing:** 2.75 units tall in the A-pose, with the origin on the floor between his feet. About 16.5k triangles and 615 KB.
- The hero's current cutout is placed with `height: 2.3`, so the seated model drops in at the same size.

## Seated model (`cody_avatar.glb`)

```
Cody                    root, identity
└─ Body                 pivot at the hips (0, 0.2, 0)   scale it for breathing
   ├─ Sweater  Pants  Shoes  Hands  Neck
   └─ HeadPivot         pivot at the neck (0, 1.0, 0)   rotate it to nod or tilt
      └─ Head  Ears  Hair
```

About 15k triangles and 364 KB, with one material per colour:

| Material | Colour (sRGB) | Notes |
|---|---|---|
| `cody_face` | texture | the head; swap its `map` to change the expression |
| `cody_skin` | `#faecdd` | ears, neck, hands |
| `cody_hair` | `#315232` | |
| `cody_sweater` | `#173623` | very dark, as in the drawing (see open questions) |
| `cody_pants` | `#901819` | |
| `cody_shoes` | `#905318` | |

All colours were sampled from the drawings. Normals are smooth, and the hair locks have marked sharp side edges, so the
ink pass draws strand lines along them, as in the drawing.

**`Idle` clip:** a 4 s seamless loop with two slow breaths on `Body` (scale) and one gentle sway and nod on
`HeadPivot` (rotation). Play it with `cody.setPose("Idle")` or an `AnimationMixer`. The hero's own motion (hop,
squash, talk bob) should go on the root or another parent, because the clip owns `Body.scale` and `HeadPivot.rotation`
while it plays. You can also skip the clip and drive those two pivots yourself.

## Switching expressions (three.js r0.170)

The face is one material, `cody_face`, on the mesh `Head`. To change the expression, swap its `map`; this needs no
recompile. The glb embeds `not_talking`. Load the others from `textures/`, and **set `flipY = false`** (glTF UV
convention), or the face comes out upside down:

```js
const loader = new THREE.TextureLoader();
const faces = {};
for (const name of ["not_talking", "talking", "smug", "sure", "evil"]) {
  const t = await loader.loadAsync(`textures/face_${name}.png`);
  t.flipY = false;
  t.colorSpace = THREE.SRGBColorSpace;
  faces[name] = t;
}
let faceMat;
gltf.scene.traverse((o) => { if (o.isMesh && o.material.name === "cody_face") faceMat = o.material; });
faceMat.map = faces.evil;        // switch
```

`cody3d.js` does all of this, plus the ink setup:

```js
import { loadCody3D } from "../3d/avatar3d/cody3d.js";
const cody = await loadCody3D({ url: "../3d/avatar3d/cody_avatar.glb", textures: "../3d/avatar3d/textures/", ink });
scene.add(cody.root);
cody.setExpression("talking");   // mouth flap: alternate talking / not_talking like avatar.js does
cody.head.rotation.z = 0.05;     // HeadPivot
cody.body.scale.y = 1.01;        // breathing
```

### With the site's `Ink` renderer

- Call `ink.inkify(mesh, { map, pixel: false })` on the face mesh. `toon()` defaults to `pixel: true`, which uses
  Nearest filtering and would make the drawn lines crunchy. The other meshes take `{ color: mat.color.getHex() }`.
- **Standing model only:** `ink.normalMaterial()` has no skinning, so the outline pass would draw the bind pose.
  `cody3d.js` swaps in `new THREE.MeshNormalMaterial()` as `userData.inkNormal` on skinned meshes. It writes the same
  packed view-space normals, and it follows the bones.

## Standing model with bones (`cody_standing.glb`)

The head, hair, face and sweater are identical to the seated model. Below the collar the body is rebuilt standing.
The bind/rest pose is an **A-pose** with the arms 50° down, which is what you want for re-rigging.

Bones (`.L` = his left = +X):

```
root ─ hips ─ spine ─ chest ─ neck ─ head
                      chest ─ shoulder.L ─ upper_arm.L ─ forearm.L ─ hand.L   (and .R)
       hips ─ thigh.L ─ shin.L ─ foot.L                                       (and .R)
```

- Every bone's **local Z points forward** (toward +Z). Rotating about local Z swings a bone in the front plane: raising
  arms, tilting the head. Rotating about local X bends it forward or back: elbows, knees, nods. Feet use Z = up.
- Skin weights are smooth and distance-based within each body part (sleeves → shoulder/upper_arm/forearm,
  legs → hips/thigh/shin, and so on). Head, hair and ears are 100% `head`. There are at most 4 influences per vertex.
- Pose clips, each a single held pose: `Idle`, `Wave`, `Cheer`, `Shrug`. Use `cody.setPose("Wave")` or `setPose(null)`
  for the A-pose. Any clip combines with any face.
- In Blender, the `.blend` has the armature (`Cody`) and the four poses as actions (fake user), ready for Rigify or
  manual re-rigging.

## Viewing

From the project root:

```bash
python3 -m http.server 8767 --bind 127.0.0.1
```

Then open `http://127.0.0.1:8767/3d/avatar3d/viewer.html`. URL options: `model=cody_standing.glb`, `pose=Wave`,
`expr=evil`, `yaw=35` (degrees), `dist`, `ty`, `up`, and `shot=1` (hides the UI, no idle loop). The page has
buttons for every expression and clip, plus a talk toggle. The seated model plays its `Idle` loop by default.

## Rebuilding

```bash
B=/Applications/Blender.app/Contents/MacOS/Blender
python3 3d/avatar3d/scripts/make_faces.py          # faces from code char/*.png
python3 3d/avatar3d/scripts/trace_hairline.py      # face outline -> scripts/hairline.json (trims the hair)
"$B" -b --factory-startup -Y --python 3d/avatar3d/scripts/build_avatar.py     # seated .blend + .glb
"$B" -b --factory-startup -Y --python 3d/avatar3d/scripts/build_standing.py   # standing .blend + .glb
"$B" -b -Y 3d/avatar3d/cody_avatar.blend --python 3d/avatar3d/scripts/render_previews.py -- overlay   # front ortho to compare with the drawing
```

- `hair.py` has the hair. Each lock visible in the drawing is listed in `FRONT_LOCKS`, with root, bend and tip in
  drawing pixels. `BACK_LOCKS` holds the tiers behind the head. Moving a tip there moves it in 3D.
- `build_avatar.py` has the drawing → 3D mapping `P()`: 1008 drawing px = 2.3 units, face centre at x = 288.
- `trace_hairline.py` counts every expression's eyes, brows and mouth as face, and every hair lock is trimmed by that
  outline. This keeps hair off a brow even where the drawing's brow touches the fringe; a stray sliver over the smug
  brow came from exactly that. `make_faces.py` has a small `ERASE` list for leftovers the filters can't separate
  (currently the bang-tip outline sitting on the smug brow's peak).

## How the hair is built

The first draft used a smooth cap with spikes stuck on, and it read as a helmet. Draft 2 copies the way well-rated
stylized hair models are built, for example the CC-BY
["anime style short hair"](https://sketchfab.com/3d-models/none-c396587aee6a4e63a6476c1400b613eb) and
["Anime Male Hair"](https://sketchfab.com/3d-models/none-8ac6702e80fc4ba68dcb3f1f793d7709) on Sketchfab: overlapping
leaf-shaped clumps that start at the crown, hug the scalp and lift into sharp tips. Those were used for technique only.
No third-party geometry is included, because their cuts aren't Cody's. His 14 visible locks are traced from his
drawing: the up-flick, the sweep into the big swoop, the fringe tips and the left-side spikes.
